# AFTERGLOW

A single-file animated landing page experiment. No build step, no dependencies.

Open index.html in a browser, or visit the GitHub Pages link.

- Morphing, hue-shifting central object with layered orbit rings
- Pointer-driven parallax and ambient spotlight
- Staggered text entrance, scroll reveals, responsive layout
- Respects prefers-reduced-motion

All visuals are CSS. Fonts from Google Fonts, with system fallbacks.
